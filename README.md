# CIIRC — Centre for Incubation, Innovation, Research and Consultancy

Next-generation institutional web experience for **CIIRC®**, a Scientific and Industrial Research Organization (SIRO) recognized by DSIR, Ministry of Science & Technology, Government of India. Joint initiative of Sri Sringeri Sharada Peetham & Jyothy Institute of Technology.

- **Live Production URL**: [https://ciirc.vercel.app](https://ciirc.vercel.app)
- **Deployment Dashboard**: [https://vercel.com/sanstack256s-projects/ciirc](https://vercel.com/sanstack256s-projects/ciirc)

## Technology Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Vanilla CSS with custom institutional design system tokens
- **Visual Identity**: Midnight scientific theme (`#030A13`), screen-space continuous atmospheric radial light field (`#3B8CFF`, `#22C7B8`), and authentic institutional telemetry
- **Icons**: Lucide React

## Institutional Content & Architecture

- **18 Research Vistas**: Advanced Materials, Polymeric Composites, Medical Devices, Micro & Nano Systems, Autonomous Systems, Remote Sensing & Polar Science, Water & Environment, and more.
- **Scientific Milestones**: Track record from 2013 founding to 38th & 39th Indian Scientific Expeditions to Antarctica and the 2019 Arctic Expedition (Svalbard).
- **Central Instrumentation Suite**: Field-Emission SEM (FE-SEM), High-Resolution XRD, FTIR, HPLC, Raman Spectroscopy, and cleanroom characterization.
- **Academic & Industry Scale**: 27+ Doctorates conferred, 50+ sponsored research projects, 300+ indexed publications, 35+ products developed, 45+ MoUs with global institutions.

## Getting Started

```bash
# Install dependencies
pnpm install

# Run development server
pnpm dev

# Build for production
pnpm build

# Start production server
pnpm start
```
